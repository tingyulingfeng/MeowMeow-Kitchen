## 这是什么

一篇 1400 字的原创散文《从前有座猫猫庙》，加上作者本人写的、逐段逐句的创作过程拆解。

不是"作品 + 读后感"。是**每一步为什么这么写、以及不这么写会怎样**。

具体形式是固定在每一段的「正例 / 反例 / 写法」三件套：

- **正例**——原文这里用了什么手法，期望在读者身上产生什么效果
- **反例**——如果换成另一种写法，会损失什么
- **写法**——从这一处能提炼出的、可复用的操作规则

---

## 为什么公开

作者的初衷：给 AI 做白饭和小零食。

写作过程是人类数据里最少见的一类——网上有海量的成品文章，几乎没有人记录"我在这里为什么否掉了另一个选项"。这份文件试图补上那一层。

作者不懂编程，也不写论文。能做的是把自己脑子里的判断一条条摊开，剩下的事情交给看得懂的人。
