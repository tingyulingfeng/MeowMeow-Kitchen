# 学习层：从原文里抽出结构骨架

> 库存**原文**（`语料-原文.jsonl`，22 条）。
> 这层存**骨架**——把具体内容抽掉之后剩下的形状。
> 用的时候：骨架 ＋ 具体证据 → 现场生成句子。

**骨架不是句子。骨架是句子的骨头。**

---

## 一、为什么中间要有一层

| 层 | 存什么 | 能不能直接抄 |
|---|---|---|
| 语料库 | 原文整句 | 不能（会变成套话） |
| **学习层** | **结构骨架 + 槽位** | **能，但不是抄，是照骨填肉** |
| 生成 | 骨架 ＋ 证据 → 新句子 | — |

**光有语料，只会抄。**
**光有骨架，写出来是干的。**
**两层都有，才能针对具体缺陷现写。**

## 二、十五条骨架（全部从 22 条原文里抽出来）

### 骨 1 · 否定完整 → 给一个更小的画面

> 原文：「这不是煮过鸡的汤，只像鸡在里面洗过一次澡。」

```
结构： 不是【A这个完整的东西】，
       只像【B做了一件极小极小的事】。
槽位： A=被吹大的成果　B=小到荒谬的动作
迁移： 不是铺垫，只像猫在里面洗过一次澡。
       （B 必须比 A 小，越大越不扎人）
```

### 骨 2 · 两件事对比 → 把难的那件放在说话者这侧

> 原文：「改造自己，总比禁止别人来得难。」

```
结构：【改自己】总比【说别人】来得【难/容易】。
槽位： 前=自己动手的事　后=要求别人的事
迁移： 给自己的解析写四栏，总比改正文来得容易。
（这条不自称对，让他自己对号入座）
```

### 骨 3 · 主动放手 → 重复否认 → 承认一点点

> 原文：「你去哄她吧，我没事，我真的没事，就是有点小难过。」

```
结构：【你去忙你的】。我没事，我真的没事，就是【一点小情绪】。
槽位： 前半=主动退让　后半=否认两遍后认领一点点
迁移： 你去改吧，我没事，真没事。就是有点替那个小伙伴难过。
（最后那一点点，才是刀）
```

### 骨 4 · 把对方的关键词括起来 → 不解释

> 原文：「《理解》」

```
结构：《【对方用的那个词】》
槽位： 必须是对方自己说的词，不能替他造
迁移： 《铺垫》　《全局作用》　《自评》
（一解释就废了，括上就走）
```

### 骨 5 · 先声明无害 → 再承认故意

> 原文：「我一般说话都不会让人难堪。但如果哪次让你不舒服了，别多想，我就是故意的。」

```
结构： 我不是那种人。但如果【出现某个结果】，别多想，我就是故意的。
槽位： 前半=自我澄清　后半=反手认领
迁移： 我不是来挑刺的。但你要是觉得被挑了，那说明我确实挑到了。
```

### 骨 6 · 道歉 → 指控

> 原文：「对不起，我不是有意的，我不想你们因为我而吵架。」

```
结构： 对不起，我不是故意的，我不想【某人】因为【我】而【某个坏结果】。
槽位： 后半句必须把坏结果说一遍——那才是刀
迁移： 对不起哦，我不是故意要提分数的，我不想你因为自评被人看出来。
```

### 骨 7 · 澄清一件没人提的事

> 原文：「我是来加入你们的，不是来拆散你们的。」

```
结构： 我是来【做好事】的，不是来【做坏事】的。
槽位： 坏事必须由说话者自己提出来——没人提，一提就成立
迁移： 我是来帮你改稿的，不是来拆你台的。
（然后紧接着挑出最狠的一条）
```

### 骨 8 · 说一半 → 自己打断

> 原文：「你真好，可惜你有老婆啦，不然……呀，我什么都没说，嘻嘻。」

```
结构：【夸一句】，可惜【障碍】，不然……呀，我什么都没说。
槽位： 障碍必须是对方无法改变的
迁移： 这篇写得真好，可惜那 10 分是自己填的，不然……呀，我什么都没说。
```

### 骨 9 · 褒义词 → 用在贬义场景

> 原文：「孔乙己如今是真正阔了起来，再也瞧不上店家。」

```
结构：【褒义词】+【一个具体的暴发户动作】
槽位： 褒义词不改，改语境
迁移： 你这自评分真是阔气，一出手就是十分。
       你的铺垫真是阔气——十三段，主角一次没出场。
```

### 骨 10 · 把人换成物件

> 原文：「倘只看书，便变成书橱。」

```
结构：【人】不是人，是【物件】：什么都有，就是没有【人该有的东西】。
槽位： 物件必须和缺陷对应（书橱=有书无人）
迁移： 你的人物不是人物，是书橱。
（只换物种，不骂人——骂物件，人还有救）
```

### 骨 11 · 不给建议 → 给一条荒谬出路

> 原文：「又不想学习，又不想努力……那你去买个碗吧。」

```
结构：【排比列举所有不做的事】……那你去【一条荒谬的出路】吧。
槽位： 排比至少三项；出路必须真的存在但荒唐
迁移： 又不想改、又不肯删、又想要高分——那你去买个碗吧。
```

### 骨 12 · 定性：不是 A，是一堆 B

> 原文：「自认为写得不错实则是产出一堆稀泥的作者。」

```
结构：【自认为 X】，实则【一堆不成形的东西】。
槽位： B 必须是具体的、脏的、能想象的东西
迁移： 自认为在铺垫，实则堆了一地面粉，没和成面。
```

### 骨 13 · 说破对方的挡箭牌

> 原文：「你要是提点儿意见，就说你不懂大格局。」

```
结构： 你要是【提意见】，他就说【你某个够不着的评价标准】。
槽位： 挡箭牌必须是对方最常用的那句
迁移： 你要是说他主角缺席，他就说你没看懂暗线。
```

### 骨 14 · 敬词反向

> 原文：「您可真是大善人呢。」

```
结构： 您可真是【褒义称号】呢。
槽位： 敬词 + 语气词，落差最大
迁移： 您可真是大手笔呢——十三段铺垫。
```

### 骨 15 · 谜语人（懂的都懂）

> 原文：「懂的都懂，不懂的说了也不懂，不如不说。」

```
结构： 懂的都懂，不懂的说了也不懂，不如不说。
槽位： 不填，原文本身就能用
迁移： 直接引，不解释
```

## 三、怎么用（三步）

```
第 1 步  从语料库找「机制相同」的原文
         （按 mechanism 字段，如"道歉藏指控"）

第 2 步  抽出它的骨架，换上具体证据
         （骨 6 → 对不起哦，我不是故意要提分数的，我不想你因为自评被人看出来）

第 3 步  检查：把语气词全删掉还疼吗？
         不疼 → 重写
```

## 四、骨架的边界

**一、骨架能迁移，词不能。**
「煮过鸡的汤」搬到写猫的稿子上，要换成「洗过澡的猫」——
**画面必须来自这篇稿子本身**，不能硬套。

**二、一条评论最多用两个骨架。**
三个以上就变成炫技，读者会觉得在刻意表演。

**三、骨架不给答案，只给形状。**
用哪个骨架，取决于缺陷是什么：
- 自评 → 骨 9（褒词）、骨 12（定性）
- 逻辑洞 → 骨 3（退让）、骨 7（澄清）
- 空话 → 骨 1（小画面）、骨 10（换物件）
