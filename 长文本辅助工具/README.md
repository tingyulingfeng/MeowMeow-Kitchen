给长文本建一份**读者状态轨迹**，然后四种用途共享它：创作、阅读、检查、评价。

不是评分器。评分只是它的一种用法。

## 核心设计（一句话）

**一份轨迹，四个出口。**

每段记：`氛围强度 0-3` / `承担功能` / `留给读者的问题`；
全局记：`曲线形态` / `伏笔台账` / `主角在场记录`。

- **创作** 拿它当脚手架，先排曲线再写句子；**写作用时不打分**
- **阅读** 拿它当地图，先看结构再看正文——给 AI 读长文时尤其有用
- **检查** 拿它找断层：强度突变、未回收伏笔、主角缺席、长块噎住
- **评价** 拿它算分，按档位出结论

---

## 三条不能松的规矩

**一、每条扣分必须带证据。** 指回段号和句子，不说"感觉不够"。

**二、同一篇评两次，分数差 ≤3 分。** 做不到就不是量化，是情绪。

**三、每句嘲讽必须挂具体证据。** 没有证据的嘲讽是骂街。

## 量化指标进度

```
P1 氛围强度提取        地基，先做
P2 落差位置与幅度      靠 P1 的序列
P3 伏笔台账与兑现率    靠 P1 的问题列
P4 笑点识别与强度      难：什么算笑点
P5 描写/叙述比例       靠句式特征
P6 暗线可探测性        目前只能人工
```

**P1 的验证方式**：拿《猫猫庙》跑一遍，提取的曲线要与作者手写的"过山车七阶段"大致吻合。吻合则地基成立；不吻合先修 P1，不往下走。
