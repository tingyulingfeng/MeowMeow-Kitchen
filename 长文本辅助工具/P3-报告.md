## 三、评分

```
落差回收 = 5 × ( 回收率 × 0.6 + 距离覆盖度 × 0.4 )  −  该埋没埋处数 × 1.0
```

猫猫庙：

```
基础分  5.00   （回收率 100%，距离覆盖 100%）
扣分    2 处 × 1.0 = 2.00
──────────────────────────
落差回收  3.00 / 5.0
```

### 为什么"收"用乘、"埋"用减

- **埋了没收**是"该做的没做完"，它稀释的是完成度 → 用比例（回收率）体现
- **该埋没埋**是"凭空多出来的东西"→ 每多一处，扣一处

两种缺陷性质不同，不该用同一种算法。
