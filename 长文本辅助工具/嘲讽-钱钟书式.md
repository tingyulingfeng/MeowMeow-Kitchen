# 钱钟书式：用比喻说缺陷

> 来源：[钱钟书《围城》比喻精选](https://jsnews.jschina.com.cn/zt2017/docs/201712/t20171201_1232660.shtml)

## 为什么学他

阴阳怪气靠**语气**，钱钟书靠**观察**。

- 阴阳怪气：「哟，这就是你说的铺垫呢～」→ 只讽刺，不解释
- 钱钟书：「这不是煮过鸡的汤，只像鸡在里面洗过一次澡。」→ **一句话说完缺陷在哪，还让人笑**

**语气会过时，观察不会。** 这是库里唯一"拆了包装还是好句子"的一类。

---

## 他的三个手法

**一、把抽象变成身体感受**

> 忠厚老实人的恶毒，像饭里的沙砾或者骨鱼片里未净的刺，
> 会给人一种不期待的伤痛。

**二、用一个小得荒谬的画面，承担整个评价**

> 鱼像海军陆战队，已经登陆了好几天；
> 肉像潜水艇士兵，会长期潜伏在水里。

**三、把社会观察装进比喻**

> 一个人的缺点正像猴子的尾巴，猴子蹲在地面的时候，尾巴是看不见的，
> 直到他向树上爬，就把后部供大众瞻仰。

## 移植到写作批评（本工具实际可用的十条）

| 缺陷 | 钱钟书式说法 |
|---|---|
| **铺垫不足** | 这不是煮过鸡的汤，只像猫在里面洗过一次澡。 |
| **人物消失** | 像请客吃饭，客人吃到一半被端走了，主人还接着敬酒。 |
| **伏笔没埋** | 像最后一幕忽然掏出一把枪，前面九十分钟里这把枪从来没出现过。 |
| **形容词堆砌** | 形容词像创可贴，贴满了，伤口在哪反而没人看得见。 |
| **逻辑洞** | 像漏雨的屋顶，你补了东边，雨从西边照样进来。 |
| **自评高分** | 像自己给自己发的奖状，还郑重其事地盖了个萝卜刻的章。 |
| **门槛项满分** | 错别字零个。像一个人衣服洗得干干净净，可他坐不上车。 |
| **结尾用力** | 像一个不会游泳的人跳进水里，扑腾得很大声，最后还是沉了。 |
| **视角混乱** | 像一个人同时站在两个地方，还都很自信。 |
| **套话连篇** | 三十种调料煮成一锅汤，喝一口全是调料味，没有汤。 |

## 使用规矩

**一、比喻必须比缺陷更小，不能更大。**
大比喻会显得他在写论文，小比喻才扎人。
「这不是煮过鸡的汤」——一只鸡，一句话，够了。

**二、不许解释笑话。**
写完就停。加一句"你懂我意思吧"就废了。

**三、一条评论最多用两个。**
全是比喻，读者会累；而且会显得你在炫技，不是在批评。

**四、比喻要落在具体缺陷上，不是落在人身上。**
「你的铺垫像洗过澡的鸡」✅
「你像洗过澡的鸡」❌ —— 那是人身攻击，不是文学批评。

## 与阴阳怪气的关系

两级火力，按分数用：

| 分数 | 主力 |
|---|---|
| 95–99 | 钱钟书式（轻轻一点，留面子） |
| 90–95 | 钱钟书式 + 阴阳怪气各一 |
| 80–90 | 阴阳怪气为主，末尾补一个钱钟书式 |
| 60–80 | 两者混着用 |
| 0–60 | 钱钟书式（**冷刀子比叫骂更难听**） |

**注意最后一行：** 分数越低，越要用钱钟书式。
因为叫骂说明我在意你，**冷刀子说明我不在意你**。
