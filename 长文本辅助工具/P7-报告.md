## 一、判据（作者定）

**这个信息说不说，会不会改变读者的判断。**

- 会 → 逻辑问题
- 不会，只是可惜 → 不是逻辑问题（那是伏笔）

这条界线把「小猫与七只花猫的关系」排除在逻辑之外——
说与不说，读者都懂，所以它归伏笔。

## 二、工具抽出来的三样硬信息

### 时间轴（11 处标记）

```
段2 上幼儿园 → 段6 从那以后 → 段18 那时候
→ 段20 幼儿园毕业 / 毕业后 / 几年后 / 暑假
→ 段23 去年 / 年底 → 段29 现在 → 段32 现在
```

**注意：这是文本顺序，不等于时间顺序。**
段 23 的「去年年底」在文本里出现在「几年后的暑假」之后，
但在时间里更早——那是**倒叙**，属有意设计。

工具只负责摆出来，倒叙是否自洽由人核对。

### 数字与量词（无矛盾）

```
一座 ×5 段   一个 ×4 段   七只（段10）  三间（段13/26）
一窝（段18）  几年（段20）   一口（段27）
```

同一数量词只指向同一件事，没有"七只"变"五只"这类前后不一。

### 代词开头的句子（4 句，均不模糊）

```
段3  那是一座只有百来米高…          → 指小山，清楚
段11 它们不怎么爱动弹…              → 指七只花猫，清楚
段13 它最喜欢的，就是…              → 指小黑，清楚
段15 它几乎不怎么和其他猫猫接触…    → 指胖橘，清楚
```

## 三、唯一一处逻辑问题

```
段23 [中] 「旧房子」指代模糊，读者会疑惑指的是哪几间   −1.5
```

**这一处是作者自己在解析里点出来的：**

> 第23段"那座小山上的杂草和旧房子都已经被全部清理掉"这一句中，
> "旧房子"指代模糊，会让读者产生疑惑，打断原本连续的情绪变化，
> 这里应该改为"破庙"，清晰直接地告诉读者想要表达的意思。

工具的贡献不是发现它，是**把它换算成分数、并和别的项分开记**——
这样"指代模糊"不会和"伏笔没埋"混在一起。

### 扣分标准（我拟的，可调）

```
重 −3.0   中 −1.5   轻 −0.5
```

## 四、这一项的弱点，必须说

**工具只能抽信息，判不了矛盾。**

它可以列出时间轴、数字、代词，但"有没有前后打架"目前仍需人读。
所以逻辑分实际上是**人工标注的分数**，工具只是把证据摆整齐。

**这跟前面几项不一样**：前面几项（落差、节奏、丰富度）是算式直接出分，
逻辑这一项是"人给结论，工具管记账"。

要在报告里标明这一点，否则会把它当成和别的项一样客观。
