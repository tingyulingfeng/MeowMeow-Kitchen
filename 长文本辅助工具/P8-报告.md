## 二、这一项为什么不能像前面几项那样算

前面几项算的是**形式**：落差几级、拐点几个、心理描写占几成。
那些东西有客观刻度。

**暗线算的是"有没有第二层"，这需要理解内容，不是数特征。**

工具能做的只有两件：把载体找出来给人看、数点破句。剩下的必须人判。

**所以这一项要接受一个事实：它是半人工的。**
（逻辑那一项也是，但逻辑至少有一块能自动查——人物消失。暗线连这块都没有。）

## 九、作者再修正：不是"点对点"，是"锚定对象的变化轨迹"

作者原话：
**暗线不应该是以某个点来判断，而是以某些锚定对象的变化过程来判定。**

这条推翻了我上一版"明面 ↔ 暗面"的对应点模型。区别在于：

| 旧模型（作废） | 新模型 |
|---|---|
| 一个点对上一个点 | **一个对象走一条轨迹** |
| 看有多少个对应 | 看轨迹完不完整、变化说不说明问题 |
| 静态 | **动态** |

### 猫猫庙的三条轨迹

```
小山   磕碜的小黑疙瘩(3) → 秘密基地(4) → 杂草旧房子被清理(23) → 青草绿树像玉石项链(30)
破庙   小山顶上破庙里的家(5) → 三间破屋屋顶蹦跶(13) → 破屋破井破院(26)
猫猫   混了个脸熟(6) → 鼠球比赛最快乐(19) → 只剩回忆肉嘟嘟(25) → 不见猫猫不见庙(33)
```

**这三条轨迹本身就是暗线。** 不需要另外解释"它代表什么"——
小山从磕碜到光鲜，读者自己会疼；破庙从家到废墟，读者自己会懂。

### 评分重建

```
深度   = 有第二层含义的锚定物比例 × 3
       + 轨迹达到 3 个状态以上的锚定物比例 × 3

契合度 = 锚定物数量（≥3 个 3 分，2 个 2 分，1 个 1 分）
       + 状态能在正文里核对上的比例 × 3
```

工具核对方式：作者写"段3 是磕碜的小黑疙瘩"，工具去段3 正文里找"磕碜"，找到才算。

### 结果

```

契合度  6.0 / 6.0   锚定物 3 个（3.0）+ 状态核对 11/11（3.0）
──────────────────────────────
合计   12.0 / 12.0
```

### 点破不再扣分

上一版按"说破扣分"给 4–5 分。新模型下，**点破只是提示，不参与判定。**

理由：轨迹本身已经承担了表达，作者偶尔点一句是共鸣，不是失误。
把它当扣分项，等于要求作者永远不许说出自己的意思。

### 这个机制的通病，必须记下来

**填得齐就给满分。**

12 分是"作者填得完整 + 正文确实对得上"换来的，
**不是工具判断出这条暗线有多好。** 如果作者随便填三个锚定物、每个写两句，
只要正文里找得到，一样能拿高分。

这跟 `carrier`、`q_resolved` 是同一个风险：**自评项必须抽查。**
以后要随机抽几条锚定物，问一句"这条轨迹真的成立吗"。
