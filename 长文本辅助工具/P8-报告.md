## 二、这一项为什么不能像前面几项那样算

前面几项算的是**形式**：落差几级、拐点几个、心理描写占几成。
那些东西有客观刻度。

**暗线算的是"有没有第二层"，这需要理解内容，不是数特征。**

工具能做的只有两件：把载体找出来给人看、数点破句。剩下的必须人判。

**所以这一项要接受一个事实：它是半人工的。**
（逻辑那一项也是，但逻辑至少有一块能自动查——人物消失。暗线连这块都没有。）

## 六、作者补的机制：暗线补充窗口

作者原话：
**可以加一个补充窗口，工具不能识别暗线或者对暗线判断有误的时候，
作者可以自己填写，然后按照作者填写的暗线进行评估。**

这条比"想办法让工具猜暗线"高明得多——**暗线本来就是作者的意图，工具不该越俎代庖。**

### 怎么运作

作者在标注里写一段 `theme`：

```json
"theme": {
  "statement": "一句话说清暗线是什么",
  "points": [
    {"surface": "明面上是什么", "under": "暗面上是什么",
     "paras": [4], "keys": ["秘密基地"]}
  ],
  "said_out_loud": 3
}
```

**工具不判暗线，只做三件事：**

1. **核对**——作者说"段4 是秘密基地"，工具就去段4 的正文里找"秘密基地"三个字。
   找不到就打 ⚠，说明作者记错了或者写的时候没落到位。
2. **算深度**——写清 2 + 每个点都有暗面 2 + 点破控制 2。
3. **算契合度**——能核对上的对应点有几个。

## 七、这一项跟逻辑那项的根本区别

- **逻辑**：工具能查一部分（人物消失、时间轴），剩下人工
- **暗线**：工具连判都判不了，**必须作者先说，工具再核对**

所以暗线这项的分数，**本质是作者自评 + 工具核账**。
报告里必须写明，否则外人会以为它是算出来的。
