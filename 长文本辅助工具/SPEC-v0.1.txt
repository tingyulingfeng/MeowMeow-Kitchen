================================================================
创作与评审工具 · 规格 v0.1
================================================================
建立：2026-11-05
依据：《猫猫庙》第二版全部解析（氛围铺垫 / 落差 / 碎片化 / 浅尝辄止 / 假结尾……）
目标：一个基于这套理论的工具，能帮人写、能挑毛病、能打分、能骂。

================================================================
一、两种模式，同一套引擎
================================================================
  draft  逐段模式：写到哪评到哪，给下一段的建议
  review 整篇模式：全文检查 + 逐段全局评估 + 总分 + 结论

两种模式共用同一套判据，区别只是"输入范围"和"输出详略"。
所以核心只有一份规则，不是两套。

================================================================
二、输出长什么样（review 模式）
================================================================
  ┌ 逐段评估
  │   第N段：氛围强度 x/3 | 承担功能 | 能不能删 | 问题
  ├ 分维度评分（每维百分制，加权合成总分）
  ├ 修改意见（按严重度排序，每条指回具体段落和句子）
  └ 结论（按总分档位选语气）

================================================================
三、维度与权重（★ 这张表需要你确认或重排）
================================================================
  编号 | 维度                | 权重 | 量化口径
  -----+---------------------+------+--------------------------------
   1   | 氛围铺垫            |  25  | 逐段氛围强度序列：有无梯度、密度够不够、
       |                     |      | 断层处是否被后文回收
   2   | 落差与回收          |  20  | 峰/谷位置是否合理、首尾是否呼应、
       |                     |      | 埋伏是否兑现（兑现率）
   3   | 语言与节奏          |  15  | 句长变化、重复词、口语/书面是否一致、
       |                     |      | 有无"噎住"的长块
   4   | 笑料与梗            |  10  | 笑点密度、位置（是否落在铺垫之后）、
       |                     |      | 是否被重复消耗
   5   | 描写与叙述          |  10  | 描写/叙述比例、是否碎片化投放、
       |                     |      | 景物是否代替情绪
   6   | 人物与逻辑          |  10  | 人物行为前后一致、信息自洽、
       |                     |      | 有没有"突然出现/消失"的东西

       |                     |      | 点破后还剩多少
  -----+---------------------+------+
       | 合计                | 100  |
  ※ 默认权重按"铺垫是主干"来分。你觉得哪一维该更重，直接改数字，总数保持 100。

四、打分规则（"严格"全靠这三条）
================================================================
规则1 **每条扣分必须带证据**
  不合格：这段铺垫不足。
  合格：第7-19段 13 段里主角参与度为零（第7、8、11、13段均无"我"的动作），
        暗线失去锚点 —— 扣 12 分。

规则2 **同一篇文章评两次，分数不能乱跳**
  这是这个工具能不能叫"量化"的唯一检验。
  做法：所有扣分项都写成可复算的判据（数数量、看位置、查关键词），
  不写"感觉不够"，因此两次跑分数应相差 ≤3 分。
  ※ 第一次实现时我会拿同一篇跑两遍验证。

规则3 **维度分先扣到下限就不扣了**
  每维最低 0 分，不出现负分；跨维度的同一条问题不重复扣。
  例：主角参与度为零，只在"氛围铺垫"扣一次，不在"人物"里再扣一次。

五、结论语气（按总分）
================================================================
  0–60   不及格    尖锐嘲讽
  60–80  一般      用力嘲讽
  80–90  还行      普通嘲讽
  90–95  不错      轻轻嘲讽
  95–99  优秀      轻轻称赞
  100    神        （保留给不该存在的东西）

**嘲讽的唯一规矩：每句嘲讽必须挂一个具体证据。**

  不合格：你写得真烂。
  合格：你花了三分之一的篇幅写猫可爱，可主角一次都没在场——
          读者爱的是猫，不是他。这三分之一，白写了。

没有证据的嘲讽是骂街，有证据的嘲讽才是批评。
这条比语气档位重要。

================================================================
六、需要"一样一样做"的量化指标
================================================================
下列指标目前只有方向，还没有可执行的算法，按优先级：

  P1 氛围强度提取（逐段 0–3）           ← 这是全系统的地基
  P2 落差位置与幅度（峰/谷/回收）        ← 靠 P1 的序列
  P3 笑点识别与强度                      ← 难点：什么算笑点
  P4 描写/叙述比例                       ← 靠句式特征粗分
  P5 暗线可探测性                        ← 目前只能人工判断

先做 P1，其余都挂在它上面。

================================================================
七、第一版做什么（本轮范围）
================================================================
  只做：P1 氛围强度提取 + 维度1（氛围铺垫）单独打分
  不做：总分、其他维度、语气输出

  理由：P1 一歪，后面全歪。而且 P1 可以用《猫猫庙》自己验证——
        它的预期曲线你已经写出来了（过山车七阶段），
        工具的提取结果应当与你的手写曲线大致吻合。
        吻合 → 地基成立；不吻合 → 先修 P1。

八、还没解决的设计问题（先记着）
================================================================
  1. 工具评分 vs 作者本意冲突时，谁对？
     暂定：工具只评"读者体验的后果"，不评"作者想表达什么"。
     即：工具可以说"这里读者会断"，不能说"你想错了"。
  2. 不同文体能不能用同一套权重？
     暂定：不能。"论文/说明文"需要另一张表，先不管。
  3. 一百篇文章里工具的分与人类的分相关性多少才算可用？
     暂定：≥0.6 才有意义，低于此只是噪音。这条要靠以后实测。
